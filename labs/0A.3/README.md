# Lesson 0A.3 — Your First SELECT

Starter queries for **[Lesson 0A.3 (script)](https://abbottics-ai.atlassian.net/wiki/spaces/DTA/pages/126353410)**.

- **Database:** AdventureWorksLT (`SalesLT` schema)
- **Query budget:** 10 — the heaviest 0A lesson

## What you'll do
- Project **specific columns** instead of `*`.
- Rename output columns with **aliases** (`AS`).
- Build **expression columns** (arithmetic, string concatenation).
- Use **`DISTINCT`** to remove duplicate rows.
- Read **two-part names** (`SalesLT.Product`) and use a table alias.

## Run it
Open [`01-your-first-select.sql`](01-your-first-select.sql), connect with the **AIDD-MS Lab (AdventureWorksLT)** profile, and run each statement with ▶. Mind the formatting — it's the house style you'll keep all course.
