# MS-0 Labs

Hands-on starter queries for **AIDD-MS-0 (SQL Foundations)** — one folder per
lesson, matching the lesson scripts in the
[DTA Confluence space](https://abbottics-ai.atlassian.net/wiki/spaces/DTA/pages/125403148).
Each `.sql` is runnable as-is and heavily commented; read it, run it, then
modify it.

All Module 0A labs use **AdventureWorksLT** (`SalesLT` schema).

| Lesson | Folder | Focus |
| --- | --- | --- |
| 0A.1 | [`0A.1`](0A.1) | The relational model: tables, rows, columns |
| 0A.2 | [`0A.2`](0A.2) | Keys and relationships |
| 0A.3 | [`0A.3`](0A.3) | Your first SELECT |

_More lessons (0A.4 → 0D) land here as their lesson scripts are published._

## How to run
Open any lesson's `.sql` file, connect with the pre-seeded **AIDD-MS Lab
(AdventureWorksLT)** profile (the MSSQL extension prompts, or pick it from the
SQL Server view), and run statements with the ▶ button. See the
[repo README](../README.md) if the lab environment isn't up yet.
